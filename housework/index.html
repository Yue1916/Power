🔗 双人同步 未连接

两台手机填同一个配对码和同一份 Firebase 配置，即可实时同步。留空则只在本机使用。
怎么拿到 Firebase 配置？（保姆级步骤）
  1. 电脑打开 console.firebase.google.com，用 Google 账号登录，新建一个项目（名字随意）。
  2. 左侧「构建 Build」→「Realtime Database 实时数据库」→ 创建数据库，位置随意，规则先选「测试模式」。
  3. 项目设置（齿轮）→「常规」→ 下滑到「你的应用」→ 点 </> 注册一个网页应用。
  4. 它会给出一段 firebaseConfig = { ... }，把大括号里的内容整段复制，粘到上面的输入框。
  5. 两台手机填一样的配对码，点「连接同步」即可。
提示：测试模式规则 30 天后过期，到期在数据库「规则」里把日期改远一点即可（这类小工具无敏感数据）。
