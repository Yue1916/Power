AWS Certified AI Practitioner (AIF-C01) 学习手册
================================================

【怎么用】
1. 双击打开「AIF-C01-学习手册.html」，用任意现代浏览器（Chrome / Edge / Firefox）即可。
   - 完全离线，无需联网、无需安装任何东西。

2. 顶部一排是「主 tab」：总览 / 领域1~5 / ⭐收藏。
   进入某个领域后，下面的圆角按钮是「子 tab」：概述、各任务(1.1/1.2…)。

3. 每个任务包含：一句话入门 → 视频笔记(中英对照) → 补考纲缺口 →
   术语速记 → AWS 服务速查卡 → 易考点/陷阱 → 闪卡 → 自测练习题。

【互动功能】（数据都存在你自己的浏览器里）
- ✍️ 我的答案：练习题里填 A/B/C/D（多选如 AC），自动判分（✓正确 / ✗待复习）。
- 🎴 闪卡 / 答案解析：点箭头展开。
- 🗒️ 加笔记：把鼠标移到内容块之间，点“➕ 加笔记”可在任意位置写笔记，自动保存。
- ⭐ 收藏：每道题右上角点“☆ 收藏”，会汇总到顶部金色的「⭐ 收藏」tab。
- 📖 全部展开：把当前领域所有内容平铺，方便用 Ctrl+F 全局搜索。

【备份 / 换设备】（重要）
- 你的笔记、答案、收藏保存在浏览器 localStorage 中。
- 顶部「💾 导出」会下载一个 JSON 备份；换电脑或换浏览器后用「📂 导入」恢复。
- 注意：不同浏览器之间不互通（Chrome 存的在 Edge 看不到），用导出/导入迁移。
- 清除浏览器缓存/站点数据可能清空记录，请定期导出备份。

【源文件（可选）】
- “源文件”文件夹里是 Markdown 笔记和一个 Python 渲染脚本 _render_html.py。
- 只想学习看 HTML 即可，不需要这些。
- 若想修改内容并重新生成 HTML：安装 Python + 运行  pip install markdown ，
  然后执行  python _render_html.py  会重新生成 AIF-C01-学习手册.html。

祝考试顺利！
