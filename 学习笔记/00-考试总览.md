## 考试基本信息

- **定位**：基础级（Foundational），面向证明对 AI 概念和 AWS AI 工具有基础了解的人群，侧重 AI 的实际业务应用。
- **目标考生**：具有长达 6 个月 AWS 上 AI/ML 使用经验；使用 AWS AI/ML 方案，但不一定需要构建。
- **计分题目**：50 道（另有 15 道不计分题，不影响分数，且不会标明）。
- **题型**：单选题、多选题、排序题、配对题。未作答计为错误，猜答案不扣分。
- **分数**：换算分 100–1000，**及格线 700**。采用补偿评分模型（只需整体通过，不要求每个部分都及格）。

## 建议掌握的 AWS 基础知识

- 核心服务及使用案例：Amazon EC2、Amazon S3、AWS Lambda、Amazon Bedrock、Amazon SageMaker AI
- 安全与合规的 AWS 责任共担模式
- 用于访问控制的 AWS IAM
- AWS 服务定价模型

## 各任务说明速查

**领域 1（20%）**
- 1.1 解释基本 AI 概念和术语
- 1.2 确定 AI 的实际使用案例
- 1.3 描述 AI/ML 开发生命周期

**领域 2（24%）**
- 2.1 解释生成式人工智能（GenAI）的基本概念
- 2.2 了解 GenAI 解决业务问题的能力和局限性
- 2.3 描述用于构建 GenAI 应用程序的 AWS 基础设施和技术

**领域 3（28%）**
- 3.1 描述设计使用基础模型（FM）的应用程序时的注意事项
- 3.2 选择有效的提示工程技术
- 3.3 描述基础模型的训练和微调过程
- 3.4 描述评估基础模型性能的方法

**领域 4（14%）**
- 4.1 解释负责任 AI 系统的开发
- 4.2 了解模型透明且可解释的重要性

**领域 5（14%）**
- 5.1 解释保护 AI 系统的方法
- 5.2 了解适用于 AI 系统的监管和合规性法规

## 考试范围内的 AWS 服务（按类别）

- **分析**：AWS Data Exchange、Amazon EMR、AWS Glue、AWS Glue DataBrew、AWS Lake Formation、Amazon OpenSearch Service、Amazon Quick、Amazon Redshift
- **云财务管理**：AWS Budgets、AWS Cost Explorer
- **计算**：Amazon EC2、AWS Lambda
- **容器**：Amazon ECS、Amazon EKS
- **数据库**：Amazon Aurora、Amazon DocumentDB、Amazon DynamoDB、Amazon ElastiCache、Amazon Neptune、Amazon RDS
- **开发工具**：Kiro、Strands Agents、Amazon Q
- **机器学习**：Amazon A2I、Amazon Bedrock、Amazon Bedrock AgentCore、Amazon Comprehend、Amazon Kendra、Amazon Lex、Amazon Nova、Amazon Personalize、Amazon Polly、Amazon Rekognition、Amazon SageMaker AI、Amazon SageMaker JumpStart、Amazon Textract、Amazon Transcribe、Amazon Translate、AWS Transform
- **管理和监管**：AWS CloudTrail、Amazon CloudWatch、AWS Config、AWS Trusted Advisor、AWS Well-Architected Tool
- **联网和内容分发**：Amazon CloudFront、Amazon VPC
- **安全性、身份与合规性**：AWS Artifact、AWS Audit Manager、AWS IAM、Amazon Inspector、AWS KMS、Amazon Macie、AWS Secrets Manager
- **存储**：Amazon S3、Amazon S3 Glacier
